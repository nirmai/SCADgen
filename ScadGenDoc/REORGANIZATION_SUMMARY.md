# Code Structure Reorganization Summary

## Overview
The project has been reorganized to improve code maintainability and clarity by separating Python source code and SCAD files into dedicated directories.

## New Directory Structure

### `Src/` - Python Source Code
All Python source files are now located in a dedicated `Src` folder:
- **Core Scripts:**
  - `ScadCodeGen.py` - Main code generation engine
  - `run_scad.py` - Script runner
  - `nlp_extractor.py` - NLP extraction utilities
  - `setup_nlp.py` - NLP setup and initialization

- **Data Processing:**
  - `generate_training_data.py` - Training data generation
  - `collect_scad_shapes.py` - SCAD shape collection
  - `fine_tune_geometry_model.py` - Model fine-tuning

- **Testing & Verification:**
  - `test_geometry_model.py` - Geometry model testing
  - `verify_nlp.py` - NLP verification
  - `debug_nlp.py` - NLP debugging utilities
  - `examples_nlp_usage.py` - Usage examples

- **Configuration & Utilities:**
  - `nlp_config.py` - NLP configuration
  - `requirements.txt` - Python dependencies
  - `run_scad.bat` - Windows batch runner
  - `runPRGM.bat` - Program runner
  - `test.txt` - Test data

### `ScadLib/` - SCAD Files Library
All OpenSCAD files are organized under `ScadLib` with three subcategories:

#### `ScadLib/generated/` - Generated SCAD Files
Output files generated by the system:
- `cube01.scad`
- `Gear01.scad`
- `gearTest.scad`
- `generated_bushing_param.scad`
- `generated_cube_param.scad`
- `generated_gear_param.scad`

#### `ScadLib/datasets/` - Training Datasets
Parameterized SCAD models used for training:
- `bushing_param.scad`
- `cube_param.scad`
- `cylinder_param.scad`
- `gear_param.scad`
- `hexboltParam.scad`
- `hexNutParam.scad`
- `sphereParam.scad`
- `torusParam.scad`
- `truncatedCone.scad`

#### `ScadLib/shapes/` - Shape Library
Basic geometric shapes for composition:
- `basic_cone.scad`
- `basic_cube.scad`
- `basic_cylinder.scad`
- `basic_sphere.scad`
- `basic_torus.scad`
- `hexagonal_prism.scad`
- `pyramid.scad`
- `rectangular_box.scad`
- `rounded_cube.scad`
